Boots the new content dir where should be?

Boots Good question, wanderer.

For this lesson, the content directory should be at the root of your project, alongside src, static, template.html, etc.

Your tree should look like:

/ ├── content/ │ └── index.md ├── src/ ├── static/ ├── template.html ├── main.sh └── ...

From there, your code (probably in src/gencontent.py or similar) will read content/index.md.
